# Changelog

All notable changes to the EngineerDNA marketing website will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-11-08

### Added
- Initial marketing website implementation with Astro 4.x
- Homepage with hero section and platform-aware install button
- How It Works page explaining EngineerDNA workflow
- Plugins page showcasing extensibility
- Community page with contribution resources
- React islands for interactive components (install button, mobile menu)
- Tailwind CSS dark mode design system
- Responsive mobile navigation
- GitHub Actions CI workflow with comprehensive quality checks
- Automated deployment to GitHub Pages
- Dependabot configuration for weekly dependency updates
- Prettier formatting with auto-fix scripts
- Dead code detection with Knip
- Claude Code agents, skills, and hooks for development automation
- Comprehensive documentation (CLAUDE.md, README.md)

### Infrastructure
- TypeScript type checking
- ESLint code quality validation
- Prettier code formatting
- Sitemap generation
- Open Graph meta tags for social sharing
- Custom domain support (engineerdna.com)
